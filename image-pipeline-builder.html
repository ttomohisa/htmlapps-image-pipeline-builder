使い方と注意事項

基本操作

  1. 画像を追加します。
  2. Resizeノードを選択し、幅や高さを設定します。
  3. Outputノードで形式と品質を選び、画像を保存します。

対応形式

入力: JPEG / PNG / WebP。出力: JPEG / PNG / WebP。

プライバシー

完全ローカル処理です。読み込んだ画像は外部サーバーへ送信しません。

PipelineとRecipeの保存

同じブラウザーですぐ使い直すならRecipeへ登録できます。別端末への移動やバックアップにはPipeline JSONを保存します。どちらにも画像ファイル本体は含まれません。

v1.0.0 の対応範囲

JPEG / PNG / WebPの画像処理、分岐、途中Preview、複数画像Batch、Recipe、Pipeline JSON、ZIP保存に対応します。画像ファイル自体はRecipeやPipelineへ保存しません。

Recipeライブラリ

よく使うPipelineをこのブラウザーに名前付きで登録し、別の画像へすぐ再利用できます。元画像や生成画像はRecipeに保存しません。

登録済みRecipe

Recipeはこのブラウザーの保存領域に保存します。別端末への移動やバックアップには「Pipeline保存」のJSONを使ってください。

テンプレートから始める

よく使う処理を実際のノードとして展開します。あとから自由に編集できます。
