使い方と注意事項

基本操作

  1. 画像を追加します。
  2. Resizeノードを選択し、幅や高さを設定します。
  3. Outputノードで形式と品質を選び、画像を保存します。

対応形式

入力: JPEG / PNG / WebP。出力: JPEG / PNG / WebP。

プライバシー

完全ローカル処理です。読み込んだ画像は外部サーバーへ送信しません。

PipelineとRecipeの保存

Recipe名は重複できません。「更新」と「削除」は確認後に反映され、元に戻せません。保存に失敗した場合は以前のRecipeが残ります。処理は一度に1件ずつ実行し、中止後も完了した結果は保存できます。保存済みRecipeは「Pipeline JSONを書き出す」でファイル名を編集して保存できます。Canvasや画像は変更せず、キャンセル・Esc・背景クリックで閉じられます。JSON読み込み中にグラフや画像一覧を変更すると古い読み込みを無効にします。画像ファイル本体は含まれません。

v1.0.2 の対応範囲

JPEG / PNG / WebPの画像処理、分岐、途中Preview、複数画像Batch、Recipe、Pipeline JSON、ZIP保存に対応します。画像ファイル自体はRecipeやPipelineへ保存しません。

Recipeライブラリ

よく使うPipelineをこのブラウザーに名前付きで登録し、別の画像へすぐ再利用できます。元画像や生成画像はRecipeに保存しません。

登録済みRecipe

Recipeはこのブラウザーに保存します。保存済みRecipeのバックアップには各Recipeの「Pipeline JSONを書き出す」を使います。「Pipeline保存」は現在のCanvasを書き出します。

RecipeをPipeline JSONに書き出す

保存済みRecipeの設定だけを書き出します。Canvasや画像は変更しません。拡張子は .image-pipeline.json です。

テンプレートから始める
